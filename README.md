# internship_UGent
This branch contains the versions of my scripts that were adapted for use on the Flemish Supercomputer Center (VSC). While the main branch is used on my virtual machine and focuses on testing the tools on one or a few samples, the intention of the project is to scale the analysis to larger datasets so that benchmarking between tools can be performed. For this reason, part of the workflow is moved to the VSC, where I have access to more storage, memory, and computational resources. The vsc_scripts branch is used to track the adjustments required to run the scripts in the VSC environment. 

The structure of this branch mirrors the main branch, containing the scripts directory with the *mouse.R and *human.R scripts for the different CNV callers. These versions are more advanced than those in the main branch, as the current development and testing take place entirely on the VSC. The human and mouse scripts are largely similar, with only minor species specific adjustments where necessary. All scripts in this branch are fully functional, in contrast to the partially completed versions on the main branch.

The script extract_cnvnator_bins.py is a dedicated Python script used after running the standard CNVnator commands. It extracts per‑bin information and prepares the data for the CNVnator.R script, which performs further processing and generates visualizations.

cnv_benchmarking.py is a Python script designed to calculate TPR, TNR, FPR, FNR, FDR and the F1 score. It requires two types of input files: one TSV file containing the actual CNVs present in the data, and one or more TSV files containing the predicted CNVs produced by the CNV detection tools. These predicted‑CNV TSV files are generated by the four *human.R scripts available in the vsc_scripts/scripts directory. The TPR, FDR and F1‑score can be visualised for different samples using the R script visualisation_benchmarking.R. This script uses the output file generated by cnv_benchmarking.py to extract the required information. The unique sample names are hard‑coded and linked to a specific coverage level, these values need to be adjusted depending on your own data.

All R scripts use a personal library path for package installation, which needs to be adjusted according to your own filesystem. Some scripts also contain hard‑coded settings for tool parameters such as windowsize and file paths, these can be modified to match your data and directory structure. The /scripts/bash/ directory contains the bash scripts used to execute the R scripts on the VSC, and it also lists the package versions used.
