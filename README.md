# internship_UGent
This branch contains the versions of my scripts that were adapted for use on the Flemish Supercomputer Center (VSC). While the main branch is used on my virtual machine and focuses on testing the tools on one or a few samples, the intention of the project is to scale the analysis to larger datasets so that benchmarking between tools can be performed. For this reason, part of the workflow is moved to the VSC, where I have access to more storage, memory, and computational resources. The vsc_scripts branch is used to track the adjustments required to run the scripts in the VSC environment.

At this stage, the branch contains only the *_mouse.R scripts, because I am working on the first project involving ten mouse samples. Only three tools are included so far, as I am still working out how to apply the remaining tools.
